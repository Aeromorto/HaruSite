# HARU

A versão atual do site estático está na raiz deste repositório: **V6.0**.

É o site em HTML, CSS e JavaScript. A cesta guarda os produtos em todas as páginas, até que a pessoa os remova.

## Versões anteriores

Nenhuma foi apagada:

- `v2/`, `v3/`, `v4/`, `v5/`
- `v5.5/`
- `v5.8/` — a raiz imediatamente anterior a esta
- `apps/` e `packages/` — a migração Next.js, NestJS e PostgreSQL
- `app/` — a experiência Next.js mais recente, que não substitui o site estático

## Abrir no computador

Na pasta do site, execute `Abrir.ps1`. O endereço local é `http://127.0.0.1:8765/`.
